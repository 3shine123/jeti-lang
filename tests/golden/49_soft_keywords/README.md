# 49_soft_keywords — 软关键字矩阵（C 超集承诺的钉子）

Jeti 的软关键字**只在被识别的语法位置是关键字，其余位置一律退化为普通
标识符**。本用例把 7 个词在字段名/局部变量名/ivar 名/方法名/选择子分段
五种标识符位全部用一遍，同时验证关键字位仍然生效。配套负例见
`tests/negative/`（拼写废除类）与 parser 单测。

## 消歧表（识别位置 / 退化条件 / 歧义优先级）

| 软关键字 | 识别位置（关键字语义） | 退化条件 | 歧义优先级裁决 |
|---|---|---|---|
| `async` | 类型限定符位：`(async T)` 方法返回类型、顶层 `async T f()`、async 块 `async ^ …`（`async` 在 `^` **前**，返回类型在 `^` **后**可省略走推导） | 其后不紧随 `^` 且不是类型起点时（`async = 5;`、`async(x)`） | `async`+`^` 恒为 async 块（Jeti 扩展，无 XOR 回退）；`async`+类型起点 → 修饰符；否则标识符 |
| `await` | 表达式前缀运算符位：后随一元起点 token（`(`、`[`、`^`、`!`、`~`、`@`、字符串/字符/数字字面量、`++`、`--`、标识符/sizeof）——判定表 doc §3.4 | 后随 `]`/`)`/`,`/运算符等不可能跟一元表达式的 token 时（`int await = 5;`、`[t await]`、`(int)await`） | 判定表命中 → 运算符；消息发送内部深度命中运算符位还要求**加小括号**（实参 `(await [x])`、接收者 `[(await [x]) m]`），裸写报错；选择子位永远优先按选择子解析 |
| `throws` | 声明尾：参数表之后、`;`/`{` 之前的 `throws` / `throws(T *)` | 尾随冒号（`throws:` = 选择子分段）、返回类型后首个 token（`- (int)throws` = 方法名）、其余一切位置 | 选择子循环只吃带冒号的分段；裸 token 活到声明尾才按注解解析 |
| `when` | switch 模式守卫位：`case <pattern> when <expr>:` | 其余位置（`int when = 1;`、字段名） | 仅在 case 标签内模式之后识别 |
| `in` | for-in 头：`for (T x in expr)` | 其余位置（`int in = 5;`、字段名） | 仅在 for 头第二槽位识别 |
| `nullable` / `nonnull` | 类型注解位：方法返回类型/参数/ivar 的类型上（无注解区域不生效） | 声明位形状（`int nullable = 5;` —— 名字在 `=`/`;`/`,`/`)` 之前）| 期待类型的位置零 lookahead 直读；两 token 形状（`nullable foo = …`）要求 decl 位形状才当注解，否则标识符 |
| `id`（**不是软关键字**——内建对象类型，按语法上下文退化） | 类型位：`id obj;`、`(id)k`、方法返回/参数类型、`id<Proto>` | **一切名字位当普通标识符**：struct/union 字段、ivar、局部/全局变量、C/ObjC/块参数名、方法名（`- (int)id`）、选择子分段（`id:`）、for-in 变量 | 类型期待位先被 parse_type_* 消费，名字位永不误判；同名组合 `id id`、`(id)id` 合法；**唯一 C 语义边界**：文件作用域枚举成员 `id` 与内建 typedef 撞普通标识符命名空间（`redefinition of 'id'`，真 ObjC 同样如此，非解析缺口） |

## 判据表

| 输出行 | 判据 |
|---|---|
| `fields=1234567` | 7 词全部作 struct 字段名（纯 C 领地） |
| `locals=10 …16` | 7 词全部作局部变量名 |
| `ivars=20 …26` | 7 词全部作 ivar 名且 `s->x` 成员访问路径正常 |
| `methods=71 72 73` | `throws`/`await` 作方法名、`throws:` 作选择子分段——关键字位不受标识符用法污染 |
| `kw=2` | `in` 仍驱动 for-in；`when` 作变量名的同时模式 `case > 100:` 仍生效 |
| `idfield=9 8` | `id` 作 struct 字段名（用户诉求形态 `struct User { int id; }`） |
| `idglobal=42 1` | 全局变量名 `id`（`int id = 42;`）+ 类型位 `id g_obj;` 同文件共存 |
| `idtype=71 73` | 类型位 `id` 内建类型正常 + 方法名 `id` / 选择子分段 `id:` + 参数名 `id`（`- (int)id:(int)id`） |
| `idlocal=7` | 局部变量名 `id` 且可赋值（`int id = 5; id += 2;`） |
| `idparam=0` | C 函数 `(id id)` 同名同现；`take_id(nil)` 返回 0 |
| `idblk=42` | 块参数名 `id`（`^(int id){ return id + 1; }` → blk(41)=42） |

## 维护规则

加新软关键字时：本文件表格加一行、golden 加字段/变量/关键字位三处用法、
负例钉住误用形态。三件事齐了才算落语法（评审意见 #5 的制度化）。
